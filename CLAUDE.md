## antislop
For UI, copy, accessibility, and responsive layout work, load `antislop` and the relevant installed skills through the Skill tool:
- UI / visual: `antislop-ui`
- Copy & text: `antislop-copywriting`
- People / accessibility: `antislop-human`
- Mobile / responsive: `antislop-layoutmobile`
Read `DESIGN.md` for visual direction and `PRODUCT.md` for product constraints.
Before starting a new session's UI work, ask when antislop applies: during the work, or after it is done.
All skills are already installed globally. Do not download skills or create missing local skill copies.
